# Laundry Services Website

A simple, responsive landing page for a laundry service business, featuring a hero section with a call-to-action and an SVG illustration.

## Features
- Responsive navbar with logo, nav links, and a mobile hamburger menu
- Hero section with heading, description, and "Book a service" CTA button
- Custom SVG illustration of a washing machine

## File Structure
## Getting Started
1. Clone or download this repository
2. Open `index.html` in your browser (or use a local server / Live Server extension in VS Code)
3. Edit `style.css` to customize colors, fonts, and layout

## Tech Stack
- HTML5
- CSS3
- Inline SVG
